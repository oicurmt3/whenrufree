Reference for colours used across When RU Free. Status slot colours are configurable per calendar; CSS defaults are from calendar.css; runtime defaults also appear in calendar-core.js and index.js. Sources: stylesheets (page.css, index.css, calendar.css, hub.css, admin.css), inline HTML (go/index.html, index.html, calendar.html), and JS string templates (index.js, hub.js, calendar-*.js, admin-*.js).
