Everything you need to know about creating and using When RU Free? calendars.

overview Overview

When RU Free? is a simple group availability tool. An organiser creates a calendar, shares the link with participants, and everyone marks their availability. The app automatically ranks the best dates based on responses. Your calendar has its own unique link with your time slots, availabiity options and date range. Everyone uses the same link and adds their name inside the calendar.

  1. Create a calendar - Set a title, date range, time slots, and status options
  2. Share the link - Send the unique URL to your group
  3. Add availability - Each person adds their name, sets a PIN, and marks their slots
  4. See results - The "Best Match" section ranks optimal times

Creating a calendar takes less than 2 minutes. Once created, you'll get a unique link to share with your group. Bookmark this link -- it cannot be recovered if lost.

hub Calendar Hubs

A Hub gives your group one link to find all related calendars — useful when you run multiple polls or events (e.g. training, social, AGM).

  1. Create a Hub from the home page or Create a Hub — set a name and organiser PIN, and optionally an Access emoji that visitors must pick before the Hub (and its calendars) open
  2. Save your Hub link when prompted (copy, download .txt, email, share, or poster). The link cannot be recovered if lost. Your organiser PIN is not included in the download.
  3. Add calendars — anyone with the Hub link can tap Create new calendar in this Hub (no Hub PIN needed). To attach an existing calendar, log in as that calendar's organiser and use Add to Hub on the calendar page.
  4. Share the Hub link with participants — they pick which calendar to open (each calendar still uses its own name + PIN)
  5. Copy link or code — on the Hub page, anyone can copy the Hub link or code. Share, Email, and Download require organiser login.
  6. Organiser login — enter your PIN to remove calendars from the Hub or use Share/Email/Download on the Hub page
  7. Logout on the Hub page when you finish on a shared computer — this clears organiser access on that browser

Hub URL format: hub.html?g=Ab12Cd34. Use the Go page to open a calendar or Hub by pasting a code or full link.

Step 2

schedule Slots

Define the time options that appear for each day. These are the slots participants will mark their availability for.

Quick Add

Click preset buttons to quickly add common slots:

  • Morning Afternoon Evening - General time periods
  • Lunch Dinner - Meal times
  • All Day - Single full-day slot

Custom Slots

Add custom slots with specific times or descriptions (e.g., "9am-10am", "After work", "Session 1"). You can have 1 to 6 slots per day.

Tip: Keep slot names short (under 15 characters) for best display on mobile devices.
Step 3

toggle_on Options

These are the choices people cycle through when they click a slot. The first option is typically "yes/available" and scores highest in rankings.

Preset Status Sets

Click a preset to quickly set up common status combinations:

Preset Options
Yes / No / Maybe Classic three-way choice (default)
Available / Unavailable Simple two-way choice

Scoring Mode

Choose how the "Best Match" is calculated:

  • Rank mode: Position determines score (top option = highest score)
  • Weights mode: Manually assign point values (0-5) to each status

Custom Colours

Click the colour picker next to each option to choose a custom colour. The text colour will automatically adjust for readability.

Tip: You can have 1 to 5 status options. The order matters -- put your "best" response first.
Step 4

Select the start and end dates for your calendar. Each day in this range will show your time slots.

Click a preset to automatically set dates from today:

  • 1 week 2 weeks - Short-term planning
  • 1 month - Longer-term coordination

Exclude Weekends

Tick the Exclude (Sat/Sun) checkbox to hide weekends from the calendar. Useful for work meetings.

Step 5

admin_panel_settings Organiser (Admin)

As the organiser, you have special privileges. Set up your identity here.

Organiser Name

Your display name. This will appear with "(organiser)" in the calendar and will be listed first in the user list.

4-Digit PIN

Choose a memorable 4-digit PIN. You'll need this to:

  • Unlock your name to edit availability
  • Access organiser-only features (Share, Reset All, Delete Users)
Important: Your PIN cannot be recovered if forgotten! Choose something memorable but not obvious (avoid 1234, 0000, etc.).

People per Slot (booking)

Leave People per slot on No limit for a normal availability poll. Choose 1, 2 or More (up to 20) to turn the calendar into a booking form: each slot can then be taken by that many people, first come, first served. Bookings per person appears below it: how many slots each person can book in total across the whole calendar (default 1). Under that you can rename the Booking label (default "Booked") and pick its colour; the Options section is hidden while booking. People tap a free slot to book it straight away; you can remove bookings and Close bookings from the Bookings card. Booking settings cannot be changed later, and Blind privacy is not available for booking calendars.

Access Emoji (optional)

Turn on the Access emoji switch and pick one of 35 emoji. Anyone opening your calendar link must pick the same emoji before they can see it. It is added automatically when you copy, share, email or print the link. You can change it or turn it off later with the Settings (gear) button on the calendar. When creating inside a Hub that has an emoji, the calendar uses the Hub's emoji unless you pick its own.

Privacy Mode

Choose how much participants can see of each other's responses:

Mode What Users See What Organiser Sees
visibility Open All choices from everyone (when logged in) All choices from everyone
visibility_off Hidden Only their own choices All choices from everyone
lock Blind Only aggregate counts Only aggregate counts

Important: Users must be logged in to see other participants' individual choices in the rankings section. Unauthenticated visitors can only see aggregate counts (e.g., "3 Yes, 2 Maybe"). Privacy mode cannot be changed after the calendar is created.

hourglass_bottom After Creating Your Calendar

Once you click "Create New Calendar", you'll be redirected to your new calendar. Here's what to do:

  1. Bookmark the page immediately
    The URL contains a unique 8-character token (e.g., calendar.html?c=Ab3dEf9K) - if you lose it, the calendar cannot be recovered.
    • iPhone: Share... "Add Bookmark" or "Add to Home Screen"
    • Android: Menu... "Add to Home screen"
    • Desktop: Press Ctrl+D (Windows) or Cmd+D (Mac)
  2. Add your own availability
    Click on slots to set your availability first - this creates the coloured left borders that guide participants (visible to logged-in users only).
  3. Select your date filter (if applicable)
    If you chose "Only chosen" or "All except" mode, click the date headers to select which dates participants will see. Selected dates turn blue. Your selections auto-save.
  4. Share the link
    Use the share Share button to send the calendar to your group. The short URL is easy to share via text or messaging apps.
IMPORTANT: Immediately copy and save your calendar link. If you lose it, you can't recover it back.

person For Participants

Joining via a Hub

If you received a Hub link, open it and pick the calendar you need from the list. Then add your name and PIN on that calendar page as usual.

Adding your availability

  1. Click the person person icon to open the user list
  2. Click "Add Your Name" and enter your name + a 4-digit PIN
  3. Click on time slots to cycle through status options (e.g., Yes -> Maybe -> No -> blank)
  4. Your changes auto-save after a few seconds, or click check to save immediately

Logging in and out

To switch users or log out, click the person person icon. If you're logged in, you'll see a logout logout button next to your name. Clicking it will log you out and refresh the page.

Privacy note: You must be logged in to see other participants' individual choices in the rankings. Visitors who are not logged in can only see aggregate counts (e.g., "3 Yes, 2 Maybe").

Understanding the slots

Each slot may show a coloured left border. This indicates the organiser's choice for that slot, helping you see which times they prefer. You must be logged in to see these indicators.

Changing your responses

Simply click any slot to cycle through the options again. To clear a slot entirely, keep clicking until it returns to the default grey (no selection).

Resetting your availability

Click the delete trash icon to reset ALL your availability. This requires double confirmation (you must type "RESET") to prevent accidents.

trophy Best Match Rankings

The ranking automatically calculates the best meeting times based on everyone's responses. How scores are calculated depends on the scoring mode set when the calendar was created:

Rank Mode (default)

Position determines score - the first option scores highest:

  • 1st option (e.g., Yes) = highest score
  • 2nd option (e.g., Maybe) = medium score
  • 3rd+ options (e.g., No) = lowest score

Weights Mode

The organiser manually assigns point values (0-5) to each option:

  • Equal weights (e.g., all set to 1) - Every choice counts the same. Best for voting where you want to count how many people selected each option, not rank preferences.
  • Custom weights (e.g., 3, 2, 1, 0) - Fine-tune scoring. For example, "Confirmed = 3" counts more than "Interested = 2".

How Rankings Work

Each date/slot combination gets a total score by adding up everyone's weighted responses. Slots with the highest combined scores appear at the top. Click "View" on any ranking to see who responded and their individual statuses.

Sorting Options

All logged-in users can change how rankings are displayed using the toggle at the top of the rankings section:

  • By Match - Best scores first (default). Shows the most popular dates at the top.
  • By Date - Chronological order. Shows earliest dates first, regardless of score.

The organiser's sort preference is saved as the default that all users see when they first open the calendar. Individual users can change the toggle during their session. Use the 2 / 10 / All buttons to control how many results are shown.

Adding to your calendar

Once you've decided on a date, expand the ranking card and use:

  • Add - Opens Google Calendar with the event pre-filled
  • Download - Downloads a .ics calendar file for Outlook, Apple Calendar, etc.
  • Share - Share the date, time slot, and roster details via your device's share menu or copy to clipboard

check_circle Choosing a Final Slot (Organiser)

Once enough people have responded, the organiser can lock in a final decision directly from the rankings panel.

  1. Make sure you are logged in as the organiser
  2. Expand a rank card by tapping View
  3. Tap the green Choose button
  4. Confirm the choice in the dialog that appears

What happens when a slot is chosen

  • A green "Decided" banner appears at the top showing the chosen date and slot
  • The chosen slot is highlighted with a green outline in the calendar grid
  • All other slots are dimmed and cannot be clicked
  • The save button is hidden -- no one can change their availability
  • The chosen rank card is pinned to the top of the rankings with a green border
  • New participants can still add their name and PIN, but they cannot select slots

Reopening a calendar

If plans change, the organiser can tap the Reopen button in the decided banner. This removes the lock and allows everyone to edit their availability again. A confirmation dialog prevents accidental reopening.

Tip: The freeze is enforced on the server -- even if someone tries to save changes via the browser console, the server will reject them.

lightbulb_2 Tips for Success

  • Keep it simple - 3-4 time slots and 2-3 status options work best
  • Set your availability first - participants will see your preferences as coloured left borders
  • Choose a clear title - helps participants know what they're responding to
  • Share widely - send reminders to people who haven't responded
  • Check the rankings - the "Best Match" section automatically finds optimal times
  • Export results - use the Google Calendar or .ics download to save the final decision
  • Lock it in - once everyone has responded, use the Choose button to finalise and freeze the calendar
  • Stay active - calendars with no saves for 40 days are automatically deleted

warning Things You Can't Change After Creation

Once a calendar is created, these settings are fixed:

  • Calendar title
  • Categories
  • Time slots
  • Status options and colours
  • Date range
  • Weekend exclusion setting
  • Date display mode (All dates / Only chosen / All except)
  • Privacy mode

If you need different settings, you'll need to create a new calendar.

contact_support Troubleshooting

What happens if I forget my PIN? expand_more

Unfortunately, PINs cannot be recovered. You'll need to create a new name entry. Contact the organiser if you need your old entry removed.

Can I change my PIN? expand_more

Currently, PINs cannot be changed after creation. Choose a memorable 4-digit code when you first sign up.

Why am I locked out after entering wrong PINs? expand_more

For security, 5 wrong PINs in a row lock that name (or the Hub organiser) for 5 minutes. If it keeps happening, each lock is longer: 15 minutes, then 2 hours, then 2 days. The message tells you how long to wait.

Entering the correct PIN resets this. If you set up a passkey on your device, it still works while you are locked out and also resets it. The site admin can unlock you too.

Can I use a passkey (fingerprint or face) instead of my PIN? expand_more

Yes, on phones and computers with a fingerprint reader, face unlock, Windows Hello or a screen lock. After you log in with your PIN, tap Set up passkey when asked. Next time, pick your name and tap Use Passkey (fingerprint, face or screen lock). Your PIN always still works.

It is set up per device and per calendar. To see or remove your passkeys (for example on a lost phone), open the name list and tap the fingerprint icon next to your name. Hub organisers use the Passkey button on the Hub page. Your fingerprint or face never leaves your device.

Can I use it as a booking form (one person per slot)? expand_more

Yes. Set People per slot (under Slots) to 1, 2 or More when creating the calendar. People tap a free slot to book it, first come, first served; full slots are greyed out. The organiser can remove bookings and use Close bookings to stop changes.

What is the access emoji? expand_more

An optional extra lock on top of the secret link. The organiser picks one of 35 emoji, and anyone opening the calendar or Hub must pick the same one first. The emoji is written next to the link when the organiser copies, shares, emails or prints it. Your browser remembers it for 30 days.

A calendar in a Hub uses the Hub's emoji unless it has its own. Three wrong picks lock that device out for 5 minutes, then longer.

I don't know or forgot the emoji. What now? expand_more

Ask the organiser - it is usually in the message or poster with the link. Organisers can see and change it in Settings on any device that has already opened the calendar or Hub. If the organiser forgot it too, the site admin can remove it.

How long do calendars last? expand_more

Calendars with no activity (saves) are automatically deleted after 40 days to reduce data storage. Make sure someone saves their availability periodically to keep the calendar active, or export your results before the calendar expires.

Can I edit the calendar settings after creation? expand_more

Currently, calendar settings (title, dates, slots, status options) cannot be changed after creation. Create a new calendar if you need different settings.

Is my data secure? expand_more

The calendar link acts like a password - anyone with the link can view and participate. Only share links with trusted participants. PINs protect individual entries from being modified by others. Do not enter sensitive or private information.

Why don't I see the organiser indicators? expand_more

Organiser indicators (coloured left borders on slots) only appear when:

  • You are logged in (enter your PIN)
  • The organiser has set their availability for that slot
  • You are NOT the organiser (you don't need to see your own preferences)
  • The calendar is not in Blind mode

If you're not logged in, you won't see any individual user indicators for privacy reasons.

Does my availability save automatically? expand_more

Yes! Changes auto-save after about 4-5 seconds of inactivity. You'll see the save button spin briefly when saving. You can also click the check button to save immediately.

What do the different status colours mean? expand_more

The legend at the top of the calendar shows what each colour means. By default:

  • Green = Yes / Available
  • Yellow/Orange = Maybe / Tentative
  • Red/Blue = No / Unavailable
  • Grey = No response yet

Organisers can customise these colours when creating the calendar.

Why do I need to log in to see who responded? expand_more

For privacy, individual responses are only shown to authenticated users. This prevents casual visitors from seeing who is available when. When you expand a ranking card:

  • Not logged in: You'll see "Log in to see who responded"
  • Logged in (Open mode): You'll see the full roster with names and statuses
  • Logged in (Hidden mode): Only the organiser sees the roster
  • Logged in (Blind mode): No one sees individual responses

Aggregate counts (e.g., "3 Yes, 2 Maybe") are always visible to everyone.

What is a Calendar Hub? expand_more

A Hub is one private link that lists multiple calendars. Share the Hub once; participants pick which calendar to open. Each calendar still has its own organiser and participant PINs. See the Calendar Hubs section above.

How do I open a calendar or Hub if I only have a code? expand_more

Use the Go page. Choose Calendar or Hub, paste the code or full link, and tap Go.

How do I log out? expand_more

Click the person person icon to open the user list. If you're logged in, you'll see a logout logout button next to your name. Clicking it will log you out and refresh the page to ensure a clean state.

How do I delete a participant? (Organiser) expand_more

Organisers can remove any participant (except themselves) from the calendar:

  1. Click the person person icon to open the user list
  2. Find the participant you want to remove
  3. Click the delete trash icon next to their name
  4. Confirm the deletion when prompted

Warning: This permanently deletes the participant and all their availability data. This action cannot be undone.

Why can't I change my availability? expand_more

If you see a green "Decided" banner at the top, the organiser has locked in a final date and slot. The calendar is frozen and no one can change their availability. You can still view all the responses and rankings, but the slots are read-only. If the organiser reopens the calendar, you will be able to edit again.

How do I choose a final date as the organiser? expand_more

Once enough people have responded:

  1. Log in as the organiser
  2. Expand a rank card by tapping "View"
  3. Tap the green Choose button
  4. Confirm your choice

This freezes the calendar. To undo, tap the Reopen button in the green decided banner.

How do I change the ranking sort order? expand_more

Any logged-in user can use the toggle buttons at the top of the rankings section:

  • By Match - Shows dates with the highest combined scores first (default)
  • By Date - Shows dates in chronological order (earliest first)

You can also change how many results are shown using the 2 / 10 / All buttons. When the organiser changes the sort order, it is saved as the default for all users. Other users can change it locally during their session.

build Maintenance

Inactive calendars are removed automatically by cleanup.php. Schedule it via cron on your server (daily at low-traffic hours is recommended): 

0 3 * * * /usr/bin/php /path/to/cleanup.php >> /var/log/grape_cleanup.log 2>&1

Replace /path/to/cleanup.php with the absolute path on your host. The script should run from CLI only (not via the web). It prunes expired sessions, old rate-limit rows, and calendars past the auto-delete threshold set in Admin → Setup.
